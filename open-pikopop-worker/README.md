# Open PikoPop Render Proof

Render-only public worker for the PikoPop quality loop. It does not contain the private Animora product/control-plane source.

Purpose:
- preserve the V78 bear/rabbit/turtle visual direction as a clean-room lookdev reference;
- prove true 24fps animation on free public cloud compute;
- use distinct local Kokoro base voices for narrator and characters;
- drive mouth opening from the exact rendered speech waveform;
- force mouths closed outside each speaker's audio window;
- emit an MP4, contact sheet, audio hashes, and lip-sync/cadence QA.

This is an audition worker, not the PikoPop product source or release channel.
